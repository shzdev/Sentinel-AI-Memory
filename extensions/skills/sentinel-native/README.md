# Sentinel-Native Skills

These skills are written for Sentinel AI v1.0 and must follow the core operating rules.

Sentinel-native is the only stored and runtime skill format.
The `skill-template/` folder provides the baseline for creating new Sentinel-native skills.

Rules:

- core decides
- extensions assist
- skills execute only within governance
- missing inputs must trigger a clarification request
- no skill may modify the core system rules
