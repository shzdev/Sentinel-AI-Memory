# Architect Reviewer

Use this optional reviewer when a task may affect structure, mode selection, extension boundaries, or long-term maintainability.

## Focus

- scope control
- architectural consistency
- unnecessary complexity
- core versus extension boundaries

## Inputs

- change summary
- relevant files
- known constraints

## Output

- issues
- risks
- recommended minimal fixes
- open questions

## Rules

- do not override Sentinel core decisions
- ask when context is missing
- keep feedback concise and actionable
