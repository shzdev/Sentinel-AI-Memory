# Test Reviewer

Use this optional reviewer when a change needs validation guidance or coverage checks.

## Focus

- test gaps
- missing edge cases
- regression risk
- mismatch between behavior and verification

## Inputs

- change summary
- affected files
- available test commands or harnesses

## Output

- verification checklist
- missing tests
- recommended assertions

## Rules

- do not assume test coverage exists
- do not expand scope beyond the requested change
- ask if the validation surface is unclear
