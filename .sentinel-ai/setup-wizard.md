# Setup wizard

Quick alignment for a new contributor or a reset session.

- [ ] Open [`master-memory.md`](master-memory.md) once.
- [ ] Confirm the correct mode using [`decision-engine/mode-detection.md`](decision-engine/mode-detection.md).
- [ ] If Architect Mode is needed, follow the canonical cold-load order from [`master-memory.md`](master-memory.md).
- [ ] Confirm [`main/current-session.md`](main/current-session.md) reflects the current focus.
- [ ] If you changed schema or authorization, update [`main/relationship-memory.md`](main/relationship-memory.md).
- [ ] If you added a durable rule, update [`main/architectural-directives.md`](main/architectural-directives.md).
- [ ] After shipping, add a row in [`main/project-history.md`](main/project-history.md) and any durable task log used by the repo.
- [ ] After a bug lesson, append to `tasks/lessons.md`.
- [ ] Before writing memory, apply [`memory-policy/write-filter.md`](memory-policy/write-filter.md).

**Optional:** Start a diary file under `daily-diary/` if you need a longer narrative archive.
