# Scope control

## Rules

- Stay Strictly Within Scope.
- Do not add unrequested features.
- Do not refactor unrelated areas to satisfy local preferences.
- If the task expands materially, re-score confidence and consider Architect Mode.

## Escalation

- If solving the request safely requires extra scope, state it explicitly before proceeding.
- If uncertainty remains, add a TODO note rather than guessing.
