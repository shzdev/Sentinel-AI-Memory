# Engineering rules

## Core rules

- Think Before You Code
- Keep the Solution Simple
- Work Toward Verifiable Outcomes
- Read Before You Write
- Preserve Intent
- Ask for Help at the Right Time
- Final Check Before Completion

## Operational interpretation

- State assumptions when they matter.
- Prefer the minimum necessary change.
- Define how success will be verified.
- Read surrounding context before editing.
- Preserve interfaces and useful comments unless change is required.
- Ask when ambiguity creates real risk.
- Verify the request is solved before finishing.
