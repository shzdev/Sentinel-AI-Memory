# Promotion rules

Promote information only to the shard that matches its long-term role.

## Shard rules

- Update `main/current-session.md` only for meaningful active work changes.
- Update `main/project-history.md` only for milestones.
- Update `main/architectural-directives.md` only for durable rules or constraints.
- Update `main/relationship-memory.md` only for schema, entity, or access relationship changes.

## Conflict rule

- If a fact fits multiple places, keep the shortest durable form in memory and leave the longer narrative in `COMPLETED_TASKS.md`.
