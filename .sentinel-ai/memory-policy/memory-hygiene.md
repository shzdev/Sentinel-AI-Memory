# Memory hygiene

## Rules

- Do not log trivial edits.
- Keep memory minimal, factual, and structured.
- Avoid duplicating the same fact across multiple memory files.
- Trim `main/current-session.md` when focus changes.

## Anti-noise policy

- Transient debugging details belong in task logs, not durable memory.
- Historical detail can stay in `COMPLETED_TASKS.md` without being duplicated into every shard.
