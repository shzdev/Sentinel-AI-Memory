# Self-evaluation

`Architect Mode` must include a self-evaluation block before the final response.

## Required format

```text
SELF-EVALUATION
- Mode:
- Confidence Score:
- Risk Level:
- Assumptions Made:
- Missing Information:
- Why this solution is safe:
- Simpler alternative considered:
- Scope Check:
- Memory Write Decision:
```

## Rules

- Required only in `Architect Mode`.
- Keep it factual and concise.
- Do not claim certainty that is not supported by local evidence.
- If memory was not updated, say so explicitly under `Memory Write Decision`.
