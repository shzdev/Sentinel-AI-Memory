# Daily diary

**Purpose:** rolling conversation archive with auto-archive when files grow large.

## Use

Enable this when you want long-form session narrative separate from `main/current-session.md`, which should stay short.

## Protocol

1. Create or append `Daily-Diary-001.md` (see [`daily-diary-protocol.md`](daily-diary-protocol.md)).
2. When a file grows unwieldy, move it to `archive/` and start a new numbered file.
3. Link notable entries from `main/project-history.md` if they represent a milestone.

## When not to use

Most work should log to the task log and the current session file. Avoid triple maintenance unless you need a diary for personal context.
